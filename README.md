## 🚀 About

Personal portfolio website showcasing my work as a Senior Flutter Developer. Built with vanilla HTML, CSS, and JavaScript — no frameworks, blazing fast.

### Features

- 🎨 Dark/Light theme toggle with persistence
- ✨ Animated particle background with connecting lines
- ⌨️ Typewriter effect for role titles
- 📊 Animated counters for key statistics
- 🎯 Scroll-triggered reveal animations
- 📱 Fully responsive design
- ⚡ Zero dependencies — pure HTML/CSS/JS

## 🛠 Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)

- Google Fonts (Inter, JetBrains Mono)
- Font Awesome Icons
